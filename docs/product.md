# المنتج: الصفحات والفلو والحالات

## الفكرة

المتسابق بيختار سباق مسجّل فيه (جري أو HYROX)، ويجاوب أسئلة قليلة، وياخد خطة تدريب بالعربي لحد يوم السباق. أول أسبوع ببلاش، وبعدها يدفع مرة واحدة عشان يفتح باقي الخطة. كل أسبوع بيسجّل اللي عمله، والخطة بتتظبط على حسبه.

السوق الأول: مصر. الموسم من نوفمبر لفبراير: HYROX Cairo (14–15 نوفمبر 2026)، نص ماراثون الجونة (21 نوفمبر)، ماراثون شرم الشيخ (28 نوفمبر)، نص ماراثون الأهرامات (11–12 ديسمبر)، ماراثون الأقصر (8 يناير 2027)، ماراثون القاهرة (فبراير 2027). بعد كده الخليج.

## مين بيعمل الخطط

مفيش كوتش دايم. المحرّك بيركّب الخطة من مكتبة تمارين + قواعد أمان (`docs/engine-rules.md`). كوتش أو أخصائي علاج طبيعي يراجع القواعد مرة واحدة قبل البيع. الذكاء الاصطناعي ممنوع ياخد أي قرار تدريب.

## الصفحات

**للمتسابق:**
1. **صفحة الهبوط:** الفكرة، والسعر، و«اختار سباقك».
2. **اختيار السباق:** قايمة السباقات، أو سباق مش موجود (اسم + تاريخ + نوع + مسافة).
3. **الأسئلة:** على كذا خطوة قصيرة.
4. **أسئلة الصحة.**
5. **النتيجة:** الخطة جاهزة / ينفع بحذر / مش هنعملها + البدائل.
6. **التسجيل:** رقم الموبايل (والتأكيد بكود على واتساب لما الـ API يتفعّل).
7. **خطتي (الرئيسية):** الأسبوع الحالي، والعد التنازلي، والتقدّم.
8. **صفحة اليوم:** التمرين بالتفصيل + «خلّصته» / «فوّته» / «حاسس بحاجة».
9. **تسجيل الأسبوع:** عمل كام تمرين، الجري الطويل، الأسبوع كان إزاي، وجع، عيّان، وقت 5 كم جديد.
10. **الدفع:** بعد أول أسبوع.
11. **أسبوع السباق ويوم السباق.**
12. **بعد السباق:** يسجّل وقته، وكارت يشاركه، والسباق الجاي.
13. **الإعدادات:** يغيّر أيامه، يوقّف الخطة، ينقل لسباق تاني.

**لينا (الأدمن):** قايمة المتسابقين والحالات اللي محتاجة مراجعة فوق (وجع، عيّان، خطة واقفة)، السباقات، المدفوعات.

## الفلو

1. يدخل من ريل أو جروب جري ← يختار السباق.
2. الأسئلة ← أسئلة الصحة.
3. يشوف النتيجة وأول أسبوع ← يسجّل.
4. كل يوم تمرين: يفتح التمرين ← «خلّصته».
5. آخر كل أسبوع: يسجّل ← الأسابيع الجاية بتتولد من جديد من حالته.
6. بعد أول أسبوع: يدفع عشان يكمّل.
7. أسبوع السباق ← يوم السباق ← بعد السباق.

## الحالات الصعبة

- **أسئلة الصحة:** أي «أيوه» = مفيش خطة غير لما يأكد إن الدكتور وافق.
- **وجع دلوقتي بيزيد مع الجري:** مفيش خطة لحد ما يكشف.
- **السن أقل من 18:** مش متاح.
- **عيّان:** برد فوق الرقبة بس ← 3 أيام سهلة. حرارة أو كحة صدر أو تكسير ← راحة لحد ما يخف + يومين، وبعدها أسبوع سهل.
- **وجع وسط الخطة:** خفيف بيروح بعد الإحماء ← مفيش زيادة. بيزيد أو بيغيّر طريقة جريه ← الخطة تقف، ويكشف، وترجع أخف.
- **علامات خطر** (وجع صدر، دوخة شديدة، ضيق نفس مش طبيعي، إغماء): وقف فورًا وطوارئ. الخطة متتفتحش غير بعد تأكيد إنه كشف.
- **فوّت أيام:** أقل من أسبوع ← كمّل وخفّف. أكتر ← نفس الحجم أو نعيد. قريب من السباق ← نقترح يخلّص بس أو مسافة أقصر.
- **هدف مش واقعي:** نقول بصراحة ونقترح مسافة أقصر أو سباق أبعد.
- **السباق اتأجل أو اتلغى:** الخطة تتنقل من غير دفع تاني.
- **رمضان:** رمضان 2027 هيبدأ تقريبًا أوائل فبراير، يعني وقت ماراثون القاهرة. محتاجين قواعد رمضان قبل ما نفتح البيع للسباق ده.
- **استرجاع الفلوس:** قبل الأسبوع التاني كامل. بعدها نقل لسباق تاني.

كل القواعد الطبية لازم متخصص يراجعها قبل الإطلاق. دي مش نصيحة طبية.

## نطاق أول نسخة (MVP)

جوه: الجري (5، 10، 21.1، 42.2) و HYROX، الأسئلة، أسئلة الصحة، الخطة، أول أسبوع ببلاش، الدفع بـ Paymob، تسجيل الأسبوع، أدمن بسيط.

برة: تطبيق موبايل، ربط Strava وApple Health، لوحة كوتشات وجيمات، الإنجليزي، رسايل واتساب أوتوماتيك (لحد ما الـ API يتفعّل).
